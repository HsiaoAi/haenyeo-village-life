# Workation photos

Drop your event photos here for the phone's **Workation** app photo album.

- Name them sequentially: `photo1.jpg`, `photo2.jpg`, `photo3.jpg`, …
- Supported extensions: `.jpg`, `.jpeg`, `.png`, `.webp`.
- The album loads them in order and **stops at the first missing number**, so
  don't leave gaps (photo1, photo2, photo4 → photo4 won't show).
- Keep them reasonably sized (e.g. ≤ ~1600px, web-optimized) so the game stays snappy.

Captions are optional — add them later in `haenyeo/phone.js` in the `WK_CAPTIONS`
map, keyed by photo number, e.g. `1: 'Opening night at Hamdeok Beach'`.
